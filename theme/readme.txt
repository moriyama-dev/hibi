The writing app for the Hibi Journal plugin.

== Description ==

Hibi turns the front end of a WordPress site into a journal app. It opens straight into today's entry, saves as you type, works offline, and can be added to a phone's home screen. All data lives in the Hibi Journal plugin, which this theme requires.

Pages and posts that are not part of the app are shown in a plain reading layout.
